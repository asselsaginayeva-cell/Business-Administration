# Business Administration e-portfolio

E-portfolio of Assel Saginayeva (AIB-2602, Astana IT University), Business Administration, Trimester 1, 2026.
Company A: Ferrero. Company B: Bayan Sulu.

- `vercel/` is the finished static site (HTML, PDF reports, video). Deploy this folder to Vercel.
- `src/` holds the page sources and styles; `python3 build.py` regenerates `vercel/`.
- `deploy.py` uploads `vercel/` to Vercel with a personal token (the token is typed in, never stored).
